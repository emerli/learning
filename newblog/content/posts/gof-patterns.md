# Pattern GoF - Recap

## Creazionali (5)

| Pattern | Scopo |
|---------|-------|
| **Singleton** | Una sola istanza globale |
| **Factory Method** | Sottoclassi decidono quale oggetto creare |
| **Abstract Factory** | Famiglie di oggetti correlati |
| **Builder** | Costruzione passo-passo di oggetti complessi |
| **Prototype** | Clonare oggetti esistenti invece di crearne nuovi |

## Strutturali (7)

| Pattern | Scopo |
|---------|-------|
| **Adapter** | Interfaccia compatibile tra classi incompatibili |
| **Bridge** | Separa astrazione da implementazione |
| **Composite** | Tratta oggetti singoli e composti uniformemente |
| **Decorator** | Aggiunge responsabilità dinamicamente |
| **Facade** | Interfaccia semplificata a un sottosistema complesso |
| **Flyweight** | Condivide stato comune per risparmiare memoria |
| **Proxy** | Sostituto/placeholder per controllare l'accesso |

## Comportamentali (11)

| Pattern | Scopo |
|---------|-------|
| **Chain of Responsibility** | Passa richiesta lungo una catena di handler |
| **Command** | Incapsula richiesta come oggetto |
| **Iterator** | Attraversa una collezione senza esporre la struttura |
| **Mediator** | Centralizza comunicazione tra oggetti |
| **Memento** | Snapshot e ripristino dello stato |
| **Observer** | Notifica dipendenti quando lo stato cambia |
| **State** | Comportamento che varia con lo stato interno |
| **Strategy** | Algoritmi intercambiabili |
| **Template Method** | Scheletro dell'algoritmo, passi delegati alle sottoclassi |
| **Visitor** | Separa operazioni da strutture su cui opera |
| **Interpreter** | Rappresenta e valuta espressioni linguistiche |
